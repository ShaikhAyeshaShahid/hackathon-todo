# Constitution – Phase I

## Principles
- This is a console-based Todo application
- No database is allowed
- Tasks must be stored in memory only
- No external libraries except Python standard library

## Constraints
- The developer will NOT write code manually
- All code must be generated by AI (Gemini)
- Features are limited to basic CRUD only

## Quality Rules
- Code must be readable
- Functions must be small
- Clear separation of concerns
