# Feature: Task CRUD

## User Stories
- As a user, I can add a task
- As a user, I can view all tasks
- As a user, I can update a task
- As a user, I can delete a task
- As a user, I can mark a task as complete

## Task Fields
- id (number)
- title (string)
- description (optional)
- completed (true/false)

## Commands
- add
- list
- update
- delete
- complete
