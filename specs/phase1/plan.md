# Phase 1 – Technical Plan

## Architecture
- Single Python console application
- Tasks stored in an in-memory list
- Each task represented as a dictionary

## Components
- TaskManager class
- Console menu loop
- Input validation functions

## Data Structure
tasks = [
  {
    "id": 1,
    "title": "Buy milk",
    "description": "From store",
    "completed": false
  }
]

## Flow
1. Show menu
2. Take user input
3. Perform operation
4. Loop until exit
