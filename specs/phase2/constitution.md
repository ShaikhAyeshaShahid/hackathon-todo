# Phase II Constitution

## Principles
- This is a full-stack Todo web application
- Backend must be a REST API
- Frontend and backend must be separate
- Data must persist in a database

## Constraints
- No manual coding by the developer
- All code must be generated by AI (Gemini)
- Only specified features may be implemented

## Tech Stack
- Frontend: Next.js
- Backend: FastAPI (Python)
- Database: PostgreSQL (Neon)
- Auth: JWT-based authentication
