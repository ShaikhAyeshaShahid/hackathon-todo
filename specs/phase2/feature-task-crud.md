# Feature: Task CRUD (Web)

## User Stories
- As a user, I can sign up and log in
- As a user, I can create a task
- As a user, I can see my tasks
- As a user, I can update my task
- As a user, I can delete my task
- As a user, I can mark a task as complete

## Task Fields
- id
- user_id
- title
- description
- completed
- created_at
